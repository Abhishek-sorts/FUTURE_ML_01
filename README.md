# AI-Powered Sales Forecasting Dashboard

This project was developed as part of the Machine Learning Internship at Future Interns.

## Objective
To forecast future retail sales using machine learning and present insights through
an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Prophet (Time Series Forecasting)
- Pandas & NumPy
- Power BI

## Workflow
1. Cleaned and processed historical retail sales data
2. Engineered time-based features and seasonality
3. Trained a Prophet forecasting model
4. Generated future sales predictions
5. Built an interactive Power BI dashboard

## Key Features
- Actual vs Forecasted Sales
- Confidence intervals for predictions
- Category-wise and Region-wise analysis
- Monthly seasonality trends
- Interactive filters for business users

## Business Impact
The dashboard helps retail managers forecast demand, plan inventory,
optimize regional sales strategies, and identify top-performing categories.
